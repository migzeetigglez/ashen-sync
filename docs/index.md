# Get offa Windows / Save Channeler

**Save Channeler** (`ashen-sync`) is an open-source desktop app for syncing your own game save files to **your** cloud storage (Google Drive or Proton Drive) using [rclone](https://rclone.org/).

It runs on your computer. There is no central sync server operated by this project, and we do not receive your files or cloud credentials.

- Source: [github.com/migzeetigglez/ashen-sync](https://github.com/migzeetigglez/ashen-sync)
- How it works: see the [README](https://github.com/migzeetigglez/ashen-sync#readme)
